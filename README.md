# Virtual Stock Master

Create a fully functional, interactive web application called “CHRIST Virtual Stock Exchange” for a college CIA (Continuous Internal Assessment).

The website is a dummy stock-market trading simulation designed to assess students' understanding of:

Basics of trading

BSE, NSE, MCX and SEBI, including their roles/history

SENSEX, NIFTY 50 and Depositories

Equity/Equity Derivatives vs Commodities

Types of orders and Demat accounts

Trading sessions

Fundamental and Technical Analysis

Trading mechanism

Settlement process

Settlement failure

Risk management in settlement

The website should NOT use real money or real brokerage accounts. Everything must be virtual.

DESIGN

Create a modern professional stock-exchange dashboard inspired by platforms such as NSE/BSE trading terminals, but do not copy any existing platform's branding.

Use:

Professional financial-dashboard design

Dark navy/charcoal background

White/light text

Clean cards and tables

Responsive design

College-project appropriate UI
